# 奥利给（Apple TV 网页浏览器）

给 Apple TV 用的网页浏览器，图标是一只吐舌头的小狗。用 Siri 遥控器的触控板控制屏幕上的圆点光标，可以点链接、填表单、看网页视频。
针对欧乐影院和酷播做了适配：自动去广告，视频可以用 Apple TV 原生播放器全屏播放，支持下一集。

## 为什么 App Store 里没有

Apple 没有给 tvOS 开放网页引擎（WebKit）。系统里其实带着 WebKit，但调用它属于“私有接口”，App Store 审核不允许。
所以这类浏览器只能用 Xcode 自己编译、装到自己的 Apple TV 上，本工程就是这样用的。不要把它提交到 App Store。

## 安装到 Apple TV（大约 30 分钟，主要是下载 Xcode）

1. **安装 Xcode。** 在 Mac 的 App Store 搜索 Xcode，免费安装。第一次打开时，平台组件里勾选 **tvOS**。
   Xcode 加上 tvOS 组件大约要 20 GB 空间。
2. **登录 Apple ID。** Xcode → Settings → Accounts → 左下角「+」→ Apple ID。普通免费账号就可以。
3. **配对 Apple TV。** Mac 和 Apple TV 连同一个 Wi-Fi。
   - Apple TV 上：设置 → 遥控器与设备 → 遥控器 App 与设备。停在这个页面。
   - Mac 上：Xcode → Window → Devices and Simulators，左边会出现 Apple TV，点 Pair，输入电视上显示的验证码。
4. **打开工程。** 双击 `TVBrowser.xcodeproj`。左侧点最上面的 TVBrowser → TARGETS 里的 TVBrowser → Signing & Capabilities：
   - Team 选你的 Apple ID。
   - 如果提示 Bundle Identifier 已被占用，把 `com.xzhang.tvbrowser` 改成别的，比如 `com.你的名字.tvbrowser`。
5. **运行。** Xcode 顶部的设备菜单选你的 Apple TV，按 ⌘R。第一次会慢一些。
   - 如果 Apple TV 提示要开启「开发者模式」，按提示在设置里打开并重启 Apple TV。
   - 如果打开 App 时提示开发者不受信任，到 Apple TV 的设置 → 通用 → 设备管理 里信任你的 Apple ID。

**免费 Apple ID 装的 App 7 天后会失效。** 到时候在终端里运行下面这条命令就能重装，收藏和历史都会保留。它会自动编译、签名、装到已配对的 Apple TV 上，并打开浏览器：

```bash
./install-to-tv.sh
```

脚本默认装到名为「Living Room」的 Apple TV。电视名字不同的话，把名字加在后面，比如 `./install-to-tv.sh "客厅"`。
付费开发者账号（每年 99 美元）装的可以用一年。

只想先确认工程能编译的话，装好 Xcode 后在终端运行：

```bash
./build-check.sh
```

## 遥控器怎么用

| 操作 | 作用 |
| --- | --- |
| 在触控板上滑动 | 移动光标 |
| 按下触控板 | 点击。点到输入框会弹出键盘，可以用遥控器的麦克风语音输入 |
| 长按触控板 | 打开菜单：全屏播放、收藏、历史、缩放、电脑版/手机版、滚动模式、设置 |
| 播放/暂停键 | 网页里有视频时全屏播放；没有视频时切换「光标模式」和「滚动模式」 |
| 光标推到屏幕上下边缘 | 自动滚动页面 |
| 外圈上/下（二代遥控器） | 向上/向下翻一页 |
| 外圈左/右（二代遥控器） | 向左/向右滚动页面 |
| 返回键（‹ 或 MENU） | 后退。没有可后退的网页时回到起始页，在起始页再按一次才退出 App |
| 光标移到顶部地址栏按一下 | 输入网址或搜索 |

起始页上有搜索框和收藏的网站。设置里可以换搜索引擎（Google、Bing、百度、DuckDuckGo）、调光标速度、开关去广告、开关「视频开始播放时自动全屏」、设主页、隐藏地址栏、清除缓存和 Cookie。

光标会跟着手指的速度变化：慢慢滑时移动得少，方便精确对准；快速滑时移动得多，一下就能划过屏幕。

## 看视频

打开视频的播放页后，屏幕下方会提示「找到视频」，按 **播放/暂停键** 就会用 Apple TV 原生播放器全屏播放，从网页里已经播到的位置接着播。原生播放器里的操作和系统其他视频 App 一样：

| 操作 | 作用 |
| --- | --- |
| 按下触控板 / 播放暂停键 | 暂停、继续 |
| 左右滑动触控板 | 拖动进度 |
| 向下滑 | 打开信息面板，可以调倍速 |
| 传输栏里的「下一集」 | 播放下一集；一集播完也会自动接着播下一集 |
| 返回键 | 退出全屏，回到网页 |

原生播放器播不了的视频，会自动改用「网页内全屏」：把网页里的播放器放大铺满屏幕。这时按下触控板暂停或继续，左右键快退、快进 10 秒，左右滑动拖进度，上键或长按触控板打开播放选项（倍速、快进 30 秒、下一集），返回键退出全屏。

## 去广告

- **欧乐和酷播：** 隐藏横幅广告、轮播图里的博彩广告、侧边广告、暂停广告和 VIP 弹窗。
- **所有网站：** 拦截网页自己弹出的外站窗口。你主动点的链接照常打开。
- 去广告可以在 设置 → 去广告 里关掉。其他网站如果也想隐藏广告位，需要单独适配，规则在 `TVBrowser/Scripts/adblock.js`。

## 测试情况

已在 Xcode 27.1 的 tvOS 27.0 模拟器（Apple TV 4K 1080p）上编译运行，也装到了真的 Apple TV 4K 上。

- **App 内自检（55 项）。** 在真实的 tvOS 网页引擎里依次测试这些功能：起始页、光标点击、填表单、下拉框、内嵌框架、三种滚动、放大后点击、网页弹框、打开真实网站、跳转、后退、搜索、光标灵敏度、去广告、拦弹窗、视频检测、原生播放器、网页内全屏，以及欧乐和酷播的去广告、找视频地址和原生播放。需要联网。
- **遥控器按键界面测试。** 用模拟的 Siri 遥控器测试这些按键：确认键点击、长按打开菜单、播放/暂停键切换模式、上下键翻页、返回键后退和退出。
- **触控板滑动没法在模拟器里自动测试。** 光标移动和滚动的代码由自检直接调用来覆盖，第一次装到电视上时请亲手试一下手感。

运行自检（先在 Xcode 里把 App 装到模拟器上）：

```bash
xcrun simctl launch booted com.xzhang.tvbrowser -selftest
```

稍等半分钟，再查看结果：

```bash
xcrun simctl spawn booted log show --last 5m --style compact --predicate 'process == "TVBrowser" AND eventMessage CONTAINS "SELFTEST"'
```

运行遥控器按键测试：

```bash
xcodebuild test -project TVBrowser.xcodeproj -scheme TVBrowser -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation) (at 1080p)' CODE_SIGN_IDENTITY=-
```

## 已知限制

- 依赖系统私有接口，tvOS 大版本更新后可能失效，需要更新代码。
- Netflix、Disney+ 这类有版权保护（DRM）的视频网站播不了。YouTube 等普通视频网站一般能播，但不保证每个都行。
- 没有多标签页。
- Apple TV 的网页引擎放大页面时不会重新排版，放大后页面会超出屏幕，需要左右滚动。所以欧乐和酷播都保持 100%。
- 去广告和找视频地址的规则是按欧乐、酷播现在的网页写的，网站改版后可能需要更新。
- 按键依赖网页对模拟点击的响应，极少数网站可能点不动。

## 工程结构

| 文件 | 内容 |
| --- | --- |
| `TVBrowser/WebKitBridge/TBWebView.m` | 运行时加载 WebKit、创建 WKWebView，并转发加载事件和网页弹框 |
| `TVBrowser/WebKitBridge/TBWebKitShims.m` | 给 tvOS 补上 WebKit 需要的一个方法，避免部分网页闪退 |
| `TVBrowser/AppDelegate.swift` | 启动入口。tvOS 27 起必须用场景（Scene）方式创建窗口，否则无法启动 |
| `TVBrowser/BrowserViewController.swift` | 主界面：光标、遥控器手势、顶栏、菜单、收藏、历史，以及调试版里的自检 |
| `TVBrowser/PageScripts.swift` | 注入网页的脚本：点击、输入文字、选下拉框、滚动内部区域 |
| `TVBrowser/NativeVideoPlayer.swift` | 原生全屏播放器：倍速、下一集、播完自动下一集、播不了时退回网页内全屏 |
| `TVBrowser/Scripts/adblock.js` | 去广告规则（欧乐、酷播） |
| `TVBrowser/Scripts/video.js` | 找视频和播放地址、下一集链接，执行暂停、跳转、网页内全屏等指令 |
| `TVBrowser/URLInput.swift` | 判断输入的是网址还是搜索词 |
| `TVBrowser/StartPage.swift` | 起始页 |
| `TVBrowser/SiteRules.swift` | 起始页「直播」频道、要用手机版打开的页面（小红书直播间） |
| `TVBrowser/Store.swift` | 保存设置、收藏、历史 |
| `project.yml` | XcodeGen 工程描述，改完运行 `xcodegen generate` 重新生成工程 |
| `UITests/` | 遥控器按键界面测试 |
| `Tests/` | 网址解析测试和网页脚本测试页 |
| `tools/make_icons.py` | 用 `tools/icon-source/dog.png` 生成分层 App 图标和顶部横幅图（需要 Pillow） |

运行网址解析测试：

```bash
cd Tests && swiftc -o /tmp/urltest ../TVBrowser/URLInput.swift ../TVBrowser/StartPage.swift ../TVBrowser/PageScripts.swift ../TVBrowser/Store.swift ../TVBrowser/SiteRules.swift main.swift && /tmp/urltest /tmp/scripts.json
```

WKWebView 的运行时调用方式参考了开源项目 [jvanakker/tvOSBrowser](https://github.com/jvanakker/tvOSBrowser)。
